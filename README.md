# 求职进度本（Windows 本地版）

这是一个只在本机运行的求职投递管理工具，无需备案、注册或部署服务器。

## 启动

双击 `启动求职进度本.vbs`。工具会直接在浏览器中打开，不显示后台黑色窗口。网页可以正常刷新；关闭所有工具页面后，后台服务会在约 5 秒内自动结束。

`启动求职进度本.bat` 仅用于故障排查，它会显示后台运行信息。

## 功能

- 投递记录：公司、岗位、地点、投递平台、日期、当前阶段和状态
- 状态历史：每次更新阶段或状态都会保留记录
- 快速结果：一键标记收到 Offer 或未通过
- 日程：笔试、面试、测评和 Offer 安排，支持完成与错过标记
- 待跟进：日程开始两小时后仍未处理，会在首页提示
- 邮件识别：粘贴邮件正文，调用 OpenAI 兼容 API 提取信息
- 统计：阶段和渠道分布
- 本地备份：JSON 导出与恢复

## 数据位置

正式数据保存在项目目录下的 `data/job-tracker.json`。浏览器 Local Storage 只作为首次迁移和故障回退缓存；每次启动时，页面会从本地数据文件读取。程序采用临时文件写入后替换的方式，减少写入中断造成文件损坏的风险。仍建议定期在“设置”中导出备份。

本工具不会主动发送系统通知，日程只在工具内展示。

## 在线多用户版

项目同时提供基于 PostgreSQL 的小规模多用户在线模式。线上模式包含邮箱密码登录、账号数据隔离、数据库自动备份、用户 API Key 的 AES-256-GCM 加密存储，以及受服务端权限保护的管理员后台；云端启动入口为 `npm start`，不会改变上述 Windows 本地版启动方式。

部署所需环境变量、Render Blueprint 和安全注意事项见 [`ONLINE-DEPLOYMENT.md`](ONLINE-DEPLOYMENT.md)。推送到 GitHub 默认分支后，Render 可自动构建并更新线上版本，数据库不会随代码部署被覆盖。
