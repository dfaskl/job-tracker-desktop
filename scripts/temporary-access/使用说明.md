# 临时访问 CareerFlow（Windows）

1. 将压缩包完整解压，保持 `connect.cmd` 和 `connect.ps1` 在同一目录。
2. 双击 `connect.cmd`，输入服务负责人提供的 **SSH 用户名**。
3. 首次连接会显示服务器指纹。先向负责人核对，再输入 `yes`；随后按提示输入 SSH 密码（输入时不会显示字符）。已有有效 SSH 密钥或代理也可直接认证。
4. 连接成功会自动打开浏览器，使用你自己的 **网站账号** 登录。
5. 使用期间保持脚本窗口打开；关闭窗口即可断开。下次需要访问时重新运行即可，本地端口可能变化。

默认目标为 `10.12.152.159` 的 SSH 端口 `22`，转发到服务器内部 `127.0.0.1:18080`。无需 VS Code，也无需本机管理员权限（前提是 Windows 已安装 OpenSSH 客户端）。脚本不保存密码，仅监听本机回环地址，不会把服务分享给其他电脑。

网站账号与 SSH 账号不同。没有 SSH 账号时，需要由服务器管理员提供允许端口转发的账号；请勿分发项目负责人的部署私钥或管理员密码。专用账号可由管理员限制为仅允许转发到 `127.0.0.1:18080`。

此方法适用于 SSH 可连接、网站端口无法直接访问的情况。如果 SSH 也超时、服务未启动，或管理员禁用了 SSH 转发，脚本无法恢复服务。SSH 认证最长等待 3 分钟，失败时查看窗口内的原始错误。

负责人也可在 PowerShell 中指定 SSH 用户名或更换地址：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\connect.ps1 -UserName 用户名 -ServerAddress 10.12.152.159
```

关闭窗口、网络断开或电脑休眠都会中断连接。连接中断后重新运行脚本。
