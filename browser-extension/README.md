# 官网巡检助手（批量巡检版）

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 开启“开发者模式”，加载本目录并刷新求职进度本。
3. 在“投递记录”页面点击“巡检投递”。
4. 点击扩展图标，选择“授权这些官网并开始”。

扩展会遍历仍在推进且已关联官网投递页的投递记录。相同页面只访问一次，但会分别判断其中的多个岗位。已经登录的页面会自动读取并关闭。登录失效时，巡检会停在对应官网；完成登录后点击扩展图标，再选择“登录完成，继续巡检”。

权限按每次巡检实际涉及的官网域名申请。扩展不会读取或保存密码、Cookie 和输入框值，也不会保存完整页面，只临时保留岗位名称附近的一小段文字。
